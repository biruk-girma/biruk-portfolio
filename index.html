Engineering playground: pathfinding

Draw walls by dragging on the grid, then run Dijkstra or A* from the start (S) to the goal (G). Run both on the same walls to compare how many cells each one examines. The full version is AlgoStudio.

Examined cells: 0Path length: n/a

Left out on purpose: diagonal moves and weighted cells. Every step costs 1, so Dijkstra here behaves like breadth-first search. "Examined" counts cells taken off the open list. Dragging needs a mouse or touch; keyboard users can use Random walls and Run.
