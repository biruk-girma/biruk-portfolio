# Biruk Girma, portfolio

Live site: https://biruk-girma.github.io/biruk-portfolio/

A single-file portfolio (`index.html`) with no build step, no dependencies and no tracking. Fonts load from Google Fonts with system fallbacks.

## What is in it
- Searchable project explorer with case studies for NetPulse, Tutor Marketplace, AlgoStudio, the Online Bus Reservation System and Ledger
- Skills linked to the projects that demonstrate them
- A pathfinding playground (Dijkstra and A*) drawn on a canvas
- Command palette (Ctrl or Cmd + K), dark and light themes, keyboard and screen-reader support
- Shareable links to each case study, such as `#project-netpulse`

## Edit the content
Open `index.html` and edit the `CONFIG`, `PROJECTS`, `SKILLS` and `JOURNEY` data near the top of the script. Set `verified: true` on a project only when its details can be demonstrated.

## Run locally
Open `index.html` in a browser.
